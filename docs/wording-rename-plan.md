## 0. 改名总原则

| 规则 | 说明 |
|---|---|
| **主替换** | `评论` → `讨论`（名词 · 指代整个互动容器） |
| **动作替换** | `评论` → `在讨论中发言` 或 `发起讨论`（动词） |
| **单条发言** | `评论` → `发言`（指代具体的一条） |
| **回复保留** | `回复` 不变（指子层级动作）；量词统一为"条" |
| **反应保留** | 赞 / 踩 / 疑惑 不变（Reaction ≠ 讨论） |
| **mention** | 英文 `mention` → 中文 `@ 提及`（全站统一中文） |
| **后端字段** | 数据库 / API 字段名不改，只改前端可见 UI 文案 |

## 实施建议（给前端）

1. **按组件分 PR**：讨论区组件、通知中心、设置页、Charter 分别提 PR，便于 review
2. **变量名 / 字段名保留**：`totalCommentCount`、`comment_id`、`CommentSection.vue` 等代码标识符全不动，只改 template 里的中文
3. **顺手清理**：`mention` 这个英文词如果在其他地方还有出现，一起替换为"@ 提及"
4. **量词统一**：所有跟"回复"搭配的量词用 **"条"**，不用"个 / 则 / 次"
5. **i18n 未来打算**：目前是硬编码中文。如果后续做 i18n，本次改动的所有 key 建议同时建好 i18n key 映射（比如 `discuss.title` / `discuss.delete_confirm` 等），方便之后 key-based 替换
