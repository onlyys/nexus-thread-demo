## 0. 版本定位（⚠️ 本版本核心修正）

### 0.1 Nexus 产品边界

| 维度 | 定位 |
|---|---|
| **是什么** | **信息透明 · 信息呈现 · AI 辅助信息呈现 · 协助决策** |
| **不是什么** | **不是研发辅助工具**（不对标 Linear / Jira / GitHub）|

### 0.2 概念边界

全站只有两个核心概念：**Topic** + **Event**。

**⚠️ v1.1 引入的 "Thread" 概念需要撤销** —— 它带来了研发工具味，偏离了"信息呈现"的主轴。

---

## 1. 背景与目标

### 1.1 v1.1 的误判

v1.1 把 Event 里的多条发言结构化成"Thread（话题束）"，每个 Thread 是一个白底卡片，有状态 chip（💬 N 条回复 / ✅ 已转为待办 / 最新：xx · N 分钟前），支持 📌 转为待办 / ✓ 标记已解决。

这套设计**在形态上向 Linear 靠近了**，让用户感受到"这是一个研发任务管理区"，与 Nexus"信息透明+协助决策"的定位背离。

### 1.2 v1.2 的修正目标

1. **概念回归**：不再使用 "Thread"，讨论区回归"一条条发言"的扁平形态
2. **视觉降噪**：让用户的注意力集中在**"讲了什么"**，而不是状态 chip / 卡片框 / meta 信息
3. **参与门槛降低**：全站文案 wording 重新审视，让"说一句"变得轻松
4. **轻量流转**：通过 @ + 「来看」列表 让信息在人与人之间流动，而不是任务分派

---

## 2. 核心改动点

### 2.1 文案全站 check

从 v1.1 整体 wording 中抽出所有用户可见文本，重新审视是否降低了参与门槛。示例：
- `发起讨论…` → `我也来说两句…` ?
- `讨论区` → 也许不需要这个 label
- `回复 N` → `说 N 句` ?

📋 待产出：《v1.2 文案审查表》单独文档

### 2.2 讨论区视觉重构（重点）

| 维度 | v1.1 现状 | v1.2 目标 |
|---|---|---|
| **结构感来源** | Thread 白底卡片 + 边框 + 圆角 | **字体字号 / 行高 / 段间距 / 分隔线** |
| **折叠机制** | 混合态 C（首条+最新可见） | **全部展开**，不折叠 |
| **Meta 信息** | `💬 4 条回复 · ✅ 已转为待办 · 最新：肖迈 · 30 分钟前` 全显 | **全部隐藏**，时间/状态等只在 hover 或菜单里 |
| **焦点** | 卡片、chip、按钮、meta | **纯文字内容** |

**视觉方向候选**（本轮对比）：
- **A · 扁平 Notion 评论风**：无任何框线，靠 1px 分隔线 + 段间距
- **D · Twitter/X 竖线串联**：左侧 2px 浅灰竖线贯穿，延续讨论用 L 形分叉连接

📋 对比 demo：[demos/v1.2-compare.html](../demos/v1.2-compare.html)

### 2.3 富内容支持

支持 @人、链接、附件（图片 + 文件）。

| 类型 | v1.2 方案 |
|---|---|
| **@人** | 输入 `@` 立刻浮选人面板（Notion 风格） + 蓝色底色+点击跳人卡 |
| **链接** | 默认蓝色超链接（下划线用 `#bfdbfe` 淡色），hover 显 OG 预览 tooltip（不主动卡片化，不抢焦点）|
| **图片** | 内联缩略图，最大 360px 高；点击全屏 lightbox |
| **文件** | 文件 chip（图标 + 文件名 + 大小），点击下载 |

### 2.4 @ 驱动的「来看」列表（替代 v1.1 My 待办）

**逻辑**：

```
发起人 → @某人
  ↓
被 @ 的人「来看」列表 +1
  ↓
被 @ 的人进入 → 回复了 → 自动移出「来看」（信息闭环）
被 @ 的人进入 → 没回复 → 继续留在列表里
```

**关键原则**：
- 不是任务派发，是**信息请求**
- 闭环信号 = **有输出**（发言），不是"点击已读"
- 完全符合"信息透明+协助决策"定位，零研发工具味

**决策点（待定）**：
- 如果回复内容是"收到/好的/明白"这种无信息量的，是否算闭环？
  - **提议 a)** 一律算闭环（最简单，v1.2 先按 a 做）
  - b) 内容长度判断（太复杂）
  - c) 发起人手动标记（侵入）

### 2.5 转待办 / 标记已解决：入口收起

本着 Q2 的决策：**保留功能，隐藏入口**。

- 不再在讨论流里显示 chip
- 全部入口收进每条发言的 `⋯` 菜单
- 目的：不让这两个动作抢"讲了什么"的焦点
